# Urban Shakespeare

Website for Urban Shakespeare ENT, a London writers' collective (urbanshakespeare.com).

- `index.html` — the whole site in one file: Home, The Slate, Burning Cole, Ikenga, Our Story, Join.
- `logo.jpg` — the Urban Shakespeare ENT logo.

Brand colours live in the `:root` block at the top of the `<style>` in `index.html`.
